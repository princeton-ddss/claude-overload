# Claude Overload

Presentation materials for the Claude Overload workshop.

## Prerequisites

The workshop is hands-on and uses a demo repo, [`data-analyst`](https://github.com/princeton-ddss/data-analyst). You will need **Claude Code**, **git**, **uv**, and **jq** installed before starting. See [1-hello](1-hello/README.md#1-install-the-prerequisites) for installation commands and what each one is used for.

## Modules

Each module has a `README.md` for attendees and a `SCRIPT.md` for the presenter.

**Workshop 1 — Foundations** (~90 min)

1. [Hello, Claude](1-hello/README.md) — setup, slash commands, workspaces, your first prompt
2. [Memory](2-memory/README.md) — `CLAUDE.md` and auto-memory
4. [Permissions](4-permissions/README.md) — controlling tool access

**Workshop 2 — Teaching Claude your workflow** (~90 min)

3. [Skills](3-skills/README.md) — protocols Claude loads on demand
6. [Hooks](6-hooks/README.md) — deterministic enforcement and audit trails
5. [Tools and MCP](5-mcp/README.md) — connecting external systems
7. [Plugins](7-plugins/README.md) — packaging your methods for your lab
8. [Subagents](8-subagents/README.md) — delegation and fresh context
9. [Working Autonomously](9-autonomy/README.md) — running unattended with confidence

> Module numbers reflect the order the material was written, not the order it's presented.
> Workshop 2 runs 3 → 6 → 5 → 7 → 8 → 9; module 9 is the capstone and should be protected
> if time runs short.
